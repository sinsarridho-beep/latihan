Selamat Datang, Calon Software Engineer!

Sebelum terjun ke koding, mari samakan persepsi. Komputer itu ibarat koki yang sangat cepat bekerja, tapi tidak punya akal sehat. Kita harus memberinya perintah berupa Algoritma (langkah-langkah logis dan terurut). Bahasa yang kita gunakan untuk memberi perintah tersebut adalah Python.

Kenapa kita butuh GitHub?

Saat ngoding, laptop bisa saja rusak atau file tidak sengaja terhapus. Git adalah sistem "mesin waktu" yang memantau perubahan kodemu. Sedangkan GitHub adalah "Instagram-nya" para programmer; tempat kamu meng-upload kode (dari lokal ke internet) agar aman dan bisa dilihat dosen/HRD perusahaan.

Instalasi "Senjata" Super Detail

Jangan lewati satu langkah pun. Klik kotak di bawah ini satu per satu secara berurutan.

1. Install Python & Atur PATH

Ikuti persis langkah ini agar komputermu tidak error saat membaca kode Python:

  • Buka website python.org/downloads lalu klik tombol kuning "Download Python 3.x".
  • Klik dua kali file python-3.x-amd64.exe yang baru di-download.
  • STOP! Di jendela pertama yang muncul, lihat bagian BAWAH layar. Kamu WAJIB mencentang kotak bertuliskan "Add python.exe to PATH". (Jika lupa, kamu harus install ulang!).
  • Setelah dicentang, klik "Install Now" di bagian atas jendela. Tunggu hingga muncul tulisan "Setup was successful".
  • Cara Cek: Buka "Command Prompt" (CMD) di Windows, ketik python --version lalu tekan Enter. Jika muncul angka versinya, artinya sukses!

2. Install VS Code & Ekstensinya

  • Download VS Code di code.visualstudio.com. Install dengan menekan "Next" terus menerus.
  • Buka aplikasi VS Code.
  • Di sisi kiri paling pinggir, ada deretan ikon. Klik ikon ke-5 (bentuknya seperti 4 kotak, namanya Extensions).
  • Di kotak pencarian, ketik Python.
  • Pilih hasil teratas (dari Microsoft), lalu klik tombol biru Install. Ini membuat kodemu jadi berwarna-warni dan mudah dibaca.

3. Install Git & Daftar Akun GitHub

A. Membuat Akun (Di Internet):

  • Buka github.com
  • Klik Sign Up. Masukkan email kampus atau email utamamu.
  • Buat username yang profesional (misal: athaya-dev). Jangan pakai nama alay karena akan dilihat dosen/HRD!
  • Verifikasi emailmu.

B. Instalasi Git (Di Laptop):

  • Download Git dari git-scm.com untuk Windows.
  • Buka installernya. Tampilannya akan sangat banyak pilihan. JANGAN BINGUNG, cukup klik "Next" terus-menerus sampai selesai! Biarkan semuanya default.

C. Berkenalan / Konfigurasi Git (WAJIB):

Setelah terinstall, laptopmu punya Git, tapi Git-nya belum tahu siapa kamu. Kita harus berkenalan. Buka aplikasi bernama "Git Bash" di Windows (cari di menu Start).

# Ketik ini lalu Enter (ganti dengan namamu):
$ git config --global user.name "Nama Lengkapmu"
# Ketik ini lalu Enter (ganti dengan email github-mu):
$ git config --global user.email "emailmu@gmail.com"

Langkah konfigurasi ini cukup dilakukan 1 kali seumur hidup di laptopmu.

Menghubungkan Laptop ke GitHub

Langkah ini adalah yang paling sering membingungkan pemula. Bagaimana caranya memindahkan file biodata.py yang ada di laptop ke akun GitHub milikmu di internet? Berikut adalah alur lengkapnya.

Step 1: Buat "Wadah" (Repository) kosong di web GitHub

  1. Buka web Github.com, klik tombol hijau "New Repository".
  2. Beri nama: tugas-python-1.
  3. Klik tombol hijau "Create repository" di paling bawah.
  4. Akan muncul halaman berisi kode-kode (Link URL Repositori-mu). Copy URL (link) tersebut!

Step 2: Ketik mantra ini di Terminal VS Code laptopmu (Simulasi di bawah):

git init (1) Memulai mesin waktu Git di folder laptopmu ini.
git add . (2) Menandai SEMUA file di folder ini untuk disiapkan.
git commit -m "..." (3) Menyimpan versi saat ini secara lokal di laptop.
git remote add origin [URL_REPO_GITHUB] (4) KRUSIAL: Menghubungkan folder di laptop ke link wadah kosong di GitHub tadi!
git push -u origin master (5) AKSI FINAL: Mendorong file dari laptop naik (upload) ke internet!

Ayo Praktik! Ketik ke-5 urutan perintah di atas satu per satu di terminal hitam ini. Anggap URL Githubmu adalah "https://github.com/athaya/tugas.git"

athaya@laptop:~$
