Instalasi "Senjata" Super Detail

Jangan lewati satu langkah pun. Klik kotak di bawah ini satu per satu secara berurutan agar laptopmu siap dipakai ngoding.

1. Install Python & Atur PATH

Otak utama agar laptop paham bahasa Python

Ikuti persis langkah ini agar komputermu tidak error saat membaca kode Python:

  1. Buka website python.org/downloads lalu klik tombol kuning "Download Python 3.x".
  2. Klik dua kali file installer (biasanya bernama python-3.x-amd64.exe) yang baru saja di-download.
  3. SANGAT PENTING (JANGAN DI-NEXT DULU): Di halaman pertama instalasi, lihat bagian paling bawah layar. Kamu WAJIB mencentang kotak kecil bertuliskan "Add python.exe to PATH". (Kalau ini terlewat, terminal tidak akan kenal perintah Python!).
  4. Setelah dicentang, baru klik "Install Now" di bagian atas jendela. Tunggu hingga muncul tulisan "Setup was successful".
  5. Cara Cek Keberhasilan: Buka aplikasi "Command Prompt" (CMD) di Windows, ketik python --version lalu tekan Enter. Jika muncul angka versinya (misal: Python 3.12.2), artinya instalasi sempurna!

2. Install VS Code & Ekstensinya

Kanvas atau buku tulis tempat kita meracik kode

  1. Download VS Code di code.visualstudio.com. Klik tombol biru "Download for Windows/Mac".
  2. Buka installer-nya dan klik "Next" terus menerus sampai selesai.
  3. Buka aplikasi VS Code yang sudah terinstall.
  4. Di menu sebelah kiri paling pinggir, klik ikon Extensions (bentuknya seperti 4 kotak, atau tekan shortcut `Ctrl+Shift+X`).
  5. Di kolom pencarian (atas), ketik "Python".
  6. Pilih hasil teratas yang pembuatnya adalah "Microsoft" (biasanya ada centang biru), lalu klik tombol biru Install. Selesai! Ini membuat kodemu jadi berwarna-warni dan mudah dibaca.

3. Install Git & Konfigurasi Awal (Wajib)

Sistem mesin waktu dan penghubung ke akun GitHub

A. Membuat Akun (Di Internet):

  • Buka github.com lalu klik Sign Up.
  • Masukkan email kampus atau email utamamu.
  • Buat username yang profesional (misal: athaya-dev). Jangan pakai nama aneh karena akan dilihat dosen!
  • Buka emailmu dan masukkan kode verifikasi dari GitHub.

B. Instalasi Git (Di Laptop):

  • Download Git dari git-scm.com untuk OS milikmu.
  • Buka installernya. Nanti tampilannya akan sangat banyak pilihan dan checkbox. JANGAN BINGUNG, cukup klik "Next" terus-menerus sampai tombol berubah jadi "Install"! Biarkan semuanya default bawaan pabrik.

C. Berkenalan / Konfigurasi Git (PENTING):

Setelah terinstall, Git di laptopmu belum tahu siapa pemiliknya. Kita harus berkenalan. Buka "Command Prompt" (CMD) atau aplikasi "Git Bash" (cari di menu Start). Ketik dua perintah ini satu per satu (ganti dengan nama dan emailmu), lalu tekan Enter setelah tiap baris:

# Baris pertama (Ganti dengan namamu): C:\Users\Athaya> git config --global user.name "Athaya"
# Baris kedua (Ganti dengan email Githubmu): C:\Users\Athaya> git config --global user.email "athaya@gmail.com"

Ciri-ciri Berhasil: Jika setelah ditekan Enter tidak muncul pesan apa-apa (langsung kembali ke tulisan folder C:\Users\..>), maka itu 100% SUKSES! Git sengaja bekerja dalam diam. Langkah kenalan ini cukup dilakukan 1 kali seumur hidup di laptopmu.

Oh tidak, kodenya Error!

Ini hal yang sangat wajar! Kelihatannya ada tanda kutip penutup " yang terlupa di ujung kalimat baris ke-2. Gunakan template prompt AI di atas untuk latihan bertanya ke ChatGPT, atau langsung tambahkan kutipnya di teks kodemu dan klik Run lagi.

Perbaiki dulu kodenya sampai tulisan '> Selesai' muncul.

Final: Menghubungkan Laptop ke GitHub

Sekarang kita akan mengunggah file kode yang sudah sukses tadi ke Internet. Kita akan menggunakan alur modern (mengubah nama cabang lokal dari `master` menjadi `main` menggunakan -M agar sesuai dengan standar GitHub).

Step 1: Buat Wadah (Repository) di web GitHub

  1. Buka Github.com, login, klik tombol hijau "New Repository".
  2. Beri nama repo bebas (misal: tugas-python), lalu klik "Create repository".
  3. Akan muncul halaman yang banyak kodenya. Copy URL (link) di bagian atas!

Step 2: Ketikkan 6 mantra wajib ini berurutan di Terminal Simulasi di bawah:

git init (1) Memulai pengawasan mesin waktu Git di folder ini.
git add . (2) Menandai SEMUA file untuk disiapkan ke dalam koper Git.
git commit -m "oke" (3) Menyimpan status saat ini (checkpoint) di laptop secara permanen.
git branch -M main (4) PENTING: Mengubah nama cabang menjadi 'main' agar terhindar dari error.
git remote add origin (5) Menghubungkan folder laptopmu dengan Link Repository GitHub.
git push -u origin main (6) AKSI FINAL: Mendorong file naik (upload) melintasi internet!

Ayo Praktik! Untuk langkah (5), ketik saja perintahnya seperti ini:
git remote add origin https://github.com/athaya/tugas.git

Mulai ketik "git init" di bawah ini lalu tekan Enter...
